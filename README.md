# react-todolist-crud
Aplikasi TodoList CRUD ini dikembangkan menggunakan React JS dan Bootstrap untuk penugasan praktikum Pemrograman Web. Aplikasi dirancang agar pengguna dapat mengelola tugas harian secara interaktif melalui implementasi penuh operasi CRUD (Create, Read, Update, Delete), pengaturan prioritas, indikator status, dan antarmuka yang responsif.
