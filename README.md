# 📋 Aplikasi TodoList CRUD (React JS & Bootstrap)

Aplikasi TodoList CRUD interaktif ini dikembangkan menggunakan **React JS** dan **Bootstrap / React-Bootstrap** sebagai bagian dari penugasan praktikum Pemrograman Web. Aplikasi ini dirancang agar pengguna dapat mengelola daftar tugas harian secara efisien melalui implementasi penuh operasi CRUD (*Create, Read, Update, Delete*), pengaturan tingkat prioritas, indikator status, serta antarmuka yang modern dan responsif.

---

## 🛠️ Fitur Utama (CRUD)
* **Create**: Menambahkan tugas baru ke dalam daftar melalui jendela *modal form* interaktif.
* **Read**: Menampilkan seluruh data tugas secara *real-time* ke dalam tabel yang rapi.
* **Update**: Mengubah dan memperbarui informasi tugas (judul, prioritas, atau status) yang sudah ada.
* **Delete**: Menghapus tugas tertentu dari daftar dengan mudah[cite: 8].
